## 📌 О проекте
**«Муз-Арбуз»** — это веб-сервис интеллектуального подбора и рекомендации музыкальных произведений, ориентированный на индивидуальные предпочтения пользователей, их текущее настроение и контекст прослушивания. Проект реализуется поэтапно в течение семестра и направлен на освоение стандартов командной разработки программного обеспечения.

## 📁 Структура репозитория
* `docs/` — общая проектная документация, устав команды и матрицы ответственности (RACI).
* `scripts/` — вспомогательные технические скрипты для автоматизации и проверки конфигурации.
* `practical-works/` — изолированные каталоги с отчетами по выполненным самостоятельным работам (СР1 — СР8).
